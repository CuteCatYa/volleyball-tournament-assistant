# 数据模型（云数据库集合）

> 对应 PRD §8。集合名、关键字段、索引建议。敏感字段加密存储 + 前端脱敏展示。

## users
用户。`_openid` 由云开发自动注入。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 微信 openid（自动） |
| `phone` | string | 手机号（登录授权采集，可加密） |
| `nickname` / `avatar` | string | 昵称/头像 |
| `roleTags` | array | 角色标签（由赛事推导，参考 PRD §7.3） |
| `createdAt` | number | 时间戳 |

索引：`_openid`（唯一）。

## events
赛事主体。状态机：`draft → cfg → reg → draw → sched → ongoing → ended → archived`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 赛事名称 |
| `creator` | string | 创建者 openid |
| `ballType` | string | indoor / air / beach |
| `bestOf` | number | 3 / 5 |
| `groups` | array | 组别（男子/女子/混合/年龄组） |
| `location` / `dates` | object / array | 地点(经纬度)、起止日期 |
| `status` | string | 状态机 |
| `regulationVersion` | string | 规程当前版本 |
| `teamCount` | number | 队伍数 |
| `createdAt` / `updatedAt` | number | 时间戳 |

索引：`creator + status`、`status + createdAt`。

## teams
参赛队伍。状态：`draft / pending / submitted / approved / rejected / published`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `eventId` | string | 所属赛事 |
| `name` / `unit` | string | 队名 / 单位 |
| `captain` | string | 队长 openid |
| `leader` / `coach` | string | 领队 / 教练 |
| `seed` | number\|null | 种子档位（AI 建议可调） |
| `status` | string | 状态机 |
| `createdAt` | number | 时间戳 |

索引：`eventId + status`。

## players
队员。敏感信息加密 + 脱敏。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `teamId` / `eventId` | string | 所属队伍/赛事 |
| `name` | string | 姓名 |
| `gender` | string | 性别 |
| `jerseyNo` | string | 球衣号 |
| `idCard` | string | 证件号（**加密存储**，前端仅后四位） |
| `photo` | string | 照片 fileID |

索引：`teamId`、`eventId`。

## registrations
报名表实例（字段值 JSON 承载 AI 动态表单）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `teamId` / `eventId` | string | 队伍/赛事 |
| `fields` | object | 字段值 JSON（动态表单） |
| `status` | string | 审核状态 |
| `reviewComment` | string | 审核意见 |
| `submittedAt` | number | 提交时间 |

## groups
抽签结果（锁定 + 留痕）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `eventId` | string | 赛事 |
| `mode` | string | random / seeded |
| `groups` | array | 分组结果 |
| `seed` | string | 随机种子（可审计） |
| `operator` | string | 操作人 openid |
| `locked` | boolean | 是否锁定 |
| `createdAt` | number | 时间戳 |

## matches
场次与结果。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `eventId` / `groupId` | string | 赛事/分组 |
| `round` | number | 轮次 |
| `teamA` / `teamB` | string | 双方队伍 id |
| `court` / `slot` | number | 场地 / 时段 |
| `sets` | array | 局比分 `[[a,b],...]` |
| `walkover` | string\|null | 弃权方（'a'/'b'） |
| `result` | object | 引擎计算结果（胜负/局分/积分） |
| `operator` | string | 记录员 openid |
| `at` | number | 时间戳 |

索引：`eventId + round`、`groupId`。

## standings
积分榜（引擎计算）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `eventId` / `groupId` | string | 赛事/分组 |
| `teamId` | string | 队伍 |
| `played / wins / losses` | number | 场次 |
| `points` | number | 积分 |
| `setsWon / setsLost` | number | 得失局 |
| `ptsWon / ptsLost` | number | 得失分 |
| `rank` | number | 名次 |

索引：`eventId + groupId + rank`。

## orders
秩序册/成绩册资产。状态：`pending / ready / failed`。

## notices
通知公告。字段见 PRD §8；`type`（announcement/变更）、`target`（all/组别/队伍）。

## documents
文书统一管理（规程/秩序册/成绩册/战报）。关键：`aiFlag`（AI 标注）、`auditStatus`（审核状态）、`version`。

## ai_conversations
AI 客服/助手会话。`messages[]`（消息流）、`quotes[]`（来源引用）。

## audit_logs
全量留痕（抽签公正性保障）。`operator / object / action / at / before / after`。

## subscriptions
一次性订阅管理。`userOpenid / eventId / templateType / status`。

---

## 权限与安全要点

1. **服务端二次校验**：云函数内以 `cloud.getWXContext().OPENID` 为准，前端 UI 只做展示。
2. **敏感字段**：身份证等加密（云函数内用密钥），前端脱敏展示（后四位）。
3. **抽签随机**： |`draw` 云函数用 `crypto.randomInt`；结果锁定；变更写 `audit_logs`。
4. **AI 内容**：`documents.aiFlag` 显式标注，人工审核后可发布。
